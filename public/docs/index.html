Authentication & API Keys

Most public discovery endpoints are open to all visitors. For commercial throughput (up to 5,000 req/min) and advanced tools like the Bet Booking Converter, pass your API key using one of the following methods:

Authentication Headers HTTP 
# 1. Custom Header (Recommended)
x-api-key: your_api_key_here

# 2. Bearer Token Authorization
Authorization: Bearer your_api_key_here

# 3. Query Parameter (Development only)
https://scores.mynorra.xyz/api/v1/football/live?api_key=your_api_key_here
Tier League Access: Free Developer keys are limited to the top 10 world leagues (eng.1, esp.1, uefa.champions, ita.1, ger.1, fra.1, usa.1, ned.1, por.1, tur.1). Querying other competitions returns a 403 Forbidden response. Subscribing to Starter, Pro, or Whitelabel unlocks all 100+ global competitions.

Get your key instantly in the Developer Portal.

GET /api/v1/football/live

Returns global in-play matches across all 100+ supported competitions in a single, high-speed call. Features live minute clocks, current scores, and recent event summaries.

Parameter Type Description
league query string Optional competition slug (e.g., eng.1, esp.1, uefa.champions) to filter by. Defaults to all.
Example Request • cURL Terminal 
curl -s "https://scores.mynorra.xyz/api/v1/football/live" \
  -H "x-api-key: YOUR_KEY"
Example Response JSON 
{
  "status": "success",
  "count": 2,
  "live": [
    {
      "id": "700123",
      "league": { "slug": "eng.1", "name": "Premier League", "country": "England" },
      "status": { "state": "in", "clock": "64'", "period": 2, "isLive": true },
      "home": { "displayName": "Arsenal", "score": 2 },
      "away": { "displayName": "Chelsea", "score": 1 }
    }
  ]
}
GET /api/v1/football/fixtures

Query matches by date and status across all competitions. Accepts natural aliases (today, yesterday, tomorrow) or ISO dates (YYYY-MM-DD).

Parameter Type Description
date query string today, yesterday, tomorrow, or 2026-10-22
status query string all, live, scheduled, or finished
league query string Specific competition slug (e.g. ger.1)
Fetch Fixtures • JavaScript Node.js / Browser 
const response = await fetch("https://scores.mynorra.xyz/api/v1/football/fixtures?date=today&status=all");
const data = await response.json();
console.log(`Loaded ${data.count} matches today.`);
GET /api/v1/football/leagues

Retrieves the complete catalog of all 100+ actively synchronized competitions, their official country, season details, and stored match counts.

Example Request • Python Python 3 
import requests

res = requests.get("https://scores.mynorra.xyz/api/v1/football/leagues")
leagues = res.json()["leagues"]
for lg in leagues:
    print(f"{lg['name']} ({lg['country']}) - Slug: {lg['slug']}")
GET /api/v1/football/standings/:league

Full league table standings with points, games played, goal differences, wins, draws, and losses.

Example Request cURL 
curl -s "https://scores.mynorra.xyz/api/v1/football/standings/eng.1"
POST /api/booking/convert

Universal betting slip converter. Takes a booking code from a source bookmaker (e.g. SportyBet) and reconstructs the slip selections for a target bookmaker (e.g. Bet9ja, 1xBet, Betway).

Field Type Description
code string (required) The booking code to translate (e.g. BC12345)
fromProvider string (required) Source bookmaker (e.g. sportybet, bet9ja)
toProvider string (required) Target bookmaker (e.g. bet9ja, 1xbet, betway)
Convert Code • cURL Terminal 
curl -X POST "https://scores.mynorra.xyz/api/booking/convert" \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_KEY" \
  -d '{
    "code": "BC789XYZ",
    "fromProvider": "sportybet",
    "toProvider": "bet9ja"
  }'
GET /api/v1/football/training-data

Machine learning training pipeline endpoint. Streams normalized, feature-engineered in-game match telemetry, live/historical xG (expected goals), possession, shots, fouls, and differential metrics for pandas DataFrames and AI model training.

Parameter Type Description
league string (optional) Filter by competition slug (e.g. eng.1, esp.1, all). Default: all.
state string (optional) Match state: post (finished matches for outcome training), in (live in-game dynamics), or all.
limit integer (optional) Max number of samples to retrieve (1 to 1000). Default: 100.
format string (optional) Output format: json (default) or jsonl (NDJSON streaming for pandas & PyTorch).
Stream Dataset • Python / pandas Python 3 
import pandas as pd

# Stream live in-game training dataset directly into pandas DataFrame
url = "https://scores.mynorra.xyz/api/v1/football/training-data?format=jsonl&limit=1000"
df = pd.read_json(url, lines=True)
print(df[['homeTeam', 'awayTeam', 'outcome', 'features']].head())
